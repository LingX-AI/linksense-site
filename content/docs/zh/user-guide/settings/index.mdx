以下设置按用途排列。修改前先确认生效范围，涉及密码、记忆或永久删除时阅读对应说明。

## 常规设置 [#general]

进入账户菜单，选择“设置 → 常规”。

### 界面语言 [#general-界面语言]

LinkSense 支持简体中文和 English。选择语言后会立即切换界面，并把偏好保存到账号，在 Web 与 Teams 中保持一致。

帮助中心有独立语言菜单。通过 LinkSense 问号按钮进入帮助中心时，会自动使用当前界面语言。

### 执行中发送新消息 [#general-执行中发送新消息]

选择任务仍在运行时新消息的默认处理方式：

- 引导当前执行：把纯文本补充要求加入正在运行的轮次。
- 排队为下一条请求：等当前轮次结束后再启动。

包含附件或明确选择插件、Skill、知识库的请求会自动排队，即使默认偏好是引导当前执行。

设置保存失败时，页面会恢复到之前的值并显示错误。确认网络恢复后重试。

### 浏览器通知 [#general-浏览器通知]

浏览器通知默认关闭。打开“启用浏览器通知”开关时，如果尚未授权，浏览器会询问是否允许 LinkSense 发送系统通知；只有选择允许后才会启用。成功开启后，LinkSense 会立即发送一条测试通知；也可以随时点击“发送测试通知”再次检查。

如果当前浏览器尚未有效开启通知，而且浏览器支持通知、权限也没有被永久阻止，LinkSense 会在界面左下角显示通知引导卡。点击“开启”会执行与设置页相同的完整启用和测试流程；点击“暂时不用”只会在本次浏览器会话内隐藏提示，下次重新打开浏览器后仍可再次看到。权限已被浏览器阻止时不会显示无法使用的引导卡，请先在网站权限中允许通知。

这个开关只对当前登录用户和当前浏览器生效，不会同步到其他浏览器或设备。LinkSense 页面需要保持打开，页面处于后台时仍可通知，但关闭页面或浏览器后不会通知。LinkSense 不使用 Web Push 或 Service Worker 在后台推送。

启用后，普通任务或自动化进入终态时会触发通知，状态按照实际结果显示：

- 成功：任务成功完成；自动化还必须已经产生可查看的结果。
- 失败：任务执行失败，或自动化结束但没有产生可查看的结果。
- 已中断：任务或自动化被中断。

首次启用时只从当前时刻开始监听，不会补发此前已经结束的历史任务通知。

无论你是否正在查看刚刚结束的任务页，LinkSense 都会发送系统通知。通知标题显示任务名称；正文显示它是普通任务还是自动化，以及“成功”“失败”或“已中断”的实际状态。任务名称会出现在浏览器和操作系统通知界面中，但通知不会包含输入内容、回答、错误详情、附件或产物名称。点击通知会聚焦 LinkSense 并直接打开对应任务。

如果浏览器不支持通知、无法保存设置、无法连接任务完成通知服务，或通知权限已被拒绝，设置页会显示对应说明；权限、测试通知和完成监听基线全部就绪后，开关才会真正保存为开启。浏览器把既有授权重置为“询问”时，可点击“重新授权并发送测试通知”；权限被拒绝后，需要先在浏览器的网站权限中允许 LinkSense 通知，再重新打开开关。如果页面提示测试通知已发送但系统没有显示，请继续检查操作系统是否允许当前浏览器发送通知，以及是否开启了免打扰或专注模式。

### 安装到桌面或主屏幕 [#general-安装到桌面或主屏幕]

LinkSense 提供 Web 应用安装信息。浏览器支持时，可以从浏览器菜单选择“安装应用”“添加到主屏幕”或同类入口，以独立窗口打开 LinkSense。具体入口名称由浏览器和操作系统决定。

安装不会启用离线模式，LinkSense 仍需连接部署服务。安装后从主屏幕启动会回到应用入口，并继续使用浏览器保存的登录会话；共享设备上使用完毕后仍应正常退出账号。

## 个人资料与个人用量 [#profile]

进入“设置 → 个人资料”管理账号的可见信息和个人使用统计。

### 修改显示名称 [#profile-修改显示名称]

选择编辑名称，输入新名称并保存。名称会用于侧边栏、管理员用户列表和协作相关的安全展示，不会改变登录邮箱。

### 上传头像 [#profile-上传头像]

选择头像区域上传受支持的图片。页面会校验文件类型和大小；保存后 Web 与 Teams 使用同一头像。删除或替换只影响显示，不会改变任务历史归属。

### 查看个人用量 [#profile-查看个人用量]

个人资料页可显示：

- 累计 Token、任务和轮次数。
- 模型调用数、活跃天数与平均每轮 Token。
- 最近 365 天的 Token 活动热力图。
- 当前与最长连续使用天数。

这些数据用于个人了解使用情况，不是用量设置、账单或执行限制。历史任务删除后，最小活动和用量事实仍可能保留在统计中，但不会恢复任务正文。

### 无法更新 [#profile-无法更新]

检查输入是否满足页面限制，然后重试。若账号已被停用，当前会话会失效，无法继续修改资料。

## 额度与使用分析 [#quota]

进入“设置 → 额度”，查看自己的剩余额度和使用分析。开放注册用户和组织成员使用相同的页面。

### 概览 [#quota-概览]

查看本周已用、剩余额度、每周限额和下次重置时间。不限额账号仍显示实际使用量。周额度按系统时区每周一重置；管理员手动重置后，概览显示重置后的使用量，分析中的历史消费不会清空。

数值单位在中英文界面均为 credits，四舍五入显示为整数，实际扣费仍保留小数精度。小于 0.5 credits 的消费可能显示为 0，但仍计入统计。

### 分析 [#quota-分析]

可查看最近 7 天或 30 天的数据，日期按浏览器所在时区展示。30 天仅为统计周期，不是月额度限制。

- 消费历史：按用途或模型查看每日消费和分类占比，使用消费发生时的扣费记录。
- 任务用量排行：展开查看模型与用途明细，或打开原任务；未关联任务和已删除任务的消费单独汇总。
- 插件与 MCP 调用：统计保留任务中已结束的调用，包含失败调用；调用次数不等于扣费次数。
- 技能使用：同一轮次内同一技能计一次。
- 消息：统计已进入任务轮次的用户消息，按模型分类，不含 AI 回复、待发送消息和分叉复制的历史消息。

图表最多展示五个分类，较多分类合并为“其他”。独立取整后，各分类显示值之和可能与总量略有差异。

## 个性化、自定义指令与记忆 [#personalization]

进入“设置 → 个性化”配置适用于你所有未来任务的偏好。

### 自定义指令 [#personalization-自定义指令]

自定义指令适合长期稳定的要求，例如：

- 默认使用中文回答。
- 修改代码后运行相关单元测试。
- 报告中先给结论，再给依据。

保存后，指令从后续新轮次开始生效。任务中的平台规则、安全边界和管理员治理始终优先；不要在自定义指令中保存密码、Token 或其他秘密。

### 自动命名任务名称 [#personalization-自动命名任务名称]

选择任务名称自动更新的时机，切换后自动保存：

- **首次对话时**（默认）：首次发送消息时自动命名，之后保持名称不变。
- **每次对话时**：每次发送新消息时，结合最新内容和近期上下文更新名称。

手动修改的任务名称不会被自动覆盖。设置适用于新任务和已有任务的后续消息，切换时不会批量修改历史任务名称。自动命名不影响任务执行；生成失败时保留原名称。

### 显示思考内容 [#personalization-显示思考内容]

“显示思考内容”默认开启，已经保存的开关状态保持不变。开启后，任务过程中会显示模型提供的完整思考正文，并可在历史记录中回看。部分模型只提供摘要或不提供正文，这时不会显示完整正文。设置按用户自动保存，只影响展示，不会改变模型的思考强度。原有思考摘要和工具调用不受此开关影响。

任务执行中，将鼠标移到“正在思考”上，点击右侧箭头可以展开当前阶段的工具调用列表；再次点击即可收起。没有工具调用时不显示展开入口。任务完成后，可以在执行过程中回看记录。

### 记忆 [#personalization-记忆]

记忆默认关闭，你可以按需开启。开启后，LinkSense 可以从符合条件的任务中生成个人记忆，并在未来任务中使用。涉及外部工具或网页上下文的任务不会生成记忆。

关闭记忆会停止生成新记忆并停止在未来任务中使用已有记忆，但不会自动清空保存内容。

### 重置记忆 [#personalization-重置记忆]

“重置记忆”会永久删除全部个人记忆，无法撤销。它不会删除：

- 任务和消息。
- 自定义指令。
- 插件或 Skill。
- 知识库和个人设置。

确认前先区分“关闭记忆”和“重置记忆”的不同影响。

## 外观与字号 [#appearance]

进入“设置 → 外观”调整只属于你的界面显示偏好。

### 主题 [#appearance-主题]

可选择：

- 系统：跟随操作系统或宿主 WebView 的明暗偏好。
- 浅色：始终使用浅色界面。
- 深色：始终使用深色界面。

切换只改变视觉呈现，不影响任务内容、文件或执行状态。

### UI 字号 [#appearance-ui-字号]

在页面提供的范围内调整基准字号。导航、表单、按钮、设置页和任务界面会同步变化，并保持原有信息层级。

文档、Markdown、Office 或 PDF 预览中的内容字号可能由对应查看器独立控制。

### 多端一致性 [#appearance-多端一致性]

外观偏好保存到账号，在浏览器 Web 与 Teams 中保持一致。系统主题会根据当前设备分别解析，因此不同设备可能显示不同明暗模式。

如果大字号造成某个第三方文档预览过于拥挤，可使用预览自身的缩放控件，不必降低整个 LinkSense 界面字号。

## 安全与修改密码 [#security]

“设置 → 安全”用于修改本地登录密码。只使用企业单点登录且未启用本地密码的账号，可能不需要此操作。

### 修改密码 [#security-修改密码]

1. 输入当前密码。
2. 输入符合页面规则的新密码。
3. 再次输入新密码确认。
4. 提交修改。

成功后，LinkSense 会撤销现有登录会话并要求重新登录。其他设备上的旧会话也会失效。

### 密码要求 [#security-密码要求]

以页面实时校验为准。避免使用组织名称、邮箱、常见口令或在其他系统重复使用的密码。

### 忘记当前密码 [#security-忘记当前密码]

退出到登录页，使用“忘记密码或首次设置密码”申请一次性重置链接。邮件能力未配置或不可用时，请联系管理员恢复认证邮件服务。

### 安全提示 [#security-安全提示]

- LinkSense 管理员不需要知道你的密码。
- 不要在任务、插件凭据名称、MCP 配置说明或自定义指令中写入密码。
- 遇到异常登录提示时先修改密码，并把时间和非敏感现象告知管理员查询审计日志。

## 已归档任务 [#archived-tasks]

进入“设置 → 已归档任务”查看从最近任务列表移出的内容。

### 恢复任务 [#archived-tasks-恢复任务]

选择“取消归档”后，任务会回到左侧最近任务列表，并按最近更新时间参与排序。恢复不会重新运行任何历史轮次。

### 删除单个任务 [#archived-tasks-删除单个任务]

永久删除前会要求确认。删除后不能恢复任务正文、附件、消息和可访问成果。

### 清空全部归档任务 [#archived-tasks-清空全部归档任务]

“清除全部已归档任务”只影响当前账号的归档任务，不会删除未归档任务。该操作不可撤销，应先下载仍需保留的成果。

### 保留范围 [#archived-tasks-保留范围]

任务被硬删除后，为审计、安全、资源清理和用量统计保存的最小事实可能继续存在，例如任务或轮次计数、Token 与费用快照。它们不包含可用于恢复的任务标题、正文、文件内容或工具参数。
