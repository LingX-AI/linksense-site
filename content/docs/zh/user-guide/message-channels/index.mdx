先比较各渠道的支持范围，再阅读对应平台的连接步骤和故障处理。

## 消息渠道概览 [#overview]

进入“设置 → 消息渠道”，可以把 LinkSense 连接到常用聊天平台。渠道消息仍会在你的私有任务空间中处理，并受模型、能力、并发和 credits 额度限制。

### 选择渠道 [#overview-选择渠道]

| 渠道 | 连接方式 | 支持的消息 | 网络要求 |
| --- | --- | --- | --- |
| [微信](#weixin) | 扫码连接个人微信 | 扫码账号本人的文本与可转写语音 | 无需公网回调 |
| [飞书](#feishu) | 扫码创建或更新官方机器人 | 创建者的一对一私聊文本 | 出站 HTTPS 与 WebSocket，无需公网回调 |
| [企业微信](#wecom) | 管理员统一配置，成员关联本人账号 | 已关联成员的私聊文本和群内 @ 文本 | 出站 HTTPS 与长连接，无需公网回调 |
| [钉钉](#dingtalk) | 个人扫码创建、授权机器人并关联本人账号 | 本人的私聊文本和群内 @ 文本 | Stream 长连接，无需公网回调 |
| [Microsoft Teams](#teams) | 管理员统一配置 Entra/Azure Bot，成员关联本人账号 | 已关联成员的私聊、群聊或频道 @ 文本 | 必须提供公网可访问的 HTTPS 消息接收地址 |

各渠道会按成员和聊天继续对应的 LinkSense 任务；组织机器人的不同成员不会共用任务上下文。群聊回复可能被同一群中的成员看到；发送前不要包含不应在群内公开的内容。

### 在哪里查看完整结果 [#overview-在哪里查看完整结果]

消息渠道主要返回最终文本。工具调用、执行过程、附件、生成文件和过长结果请回到 LinkSense 对应任务查看。渠道暂不支持的文件或消息类型，也可以直接在 Web 端添加到任务。

### 连接前检查 [#overview-连接前检查]

- 使用你自己的平台账号或组织批准的机器人应用。
- 企业微信、钉钉和 Teams 需要将平台身份关联到本人已注册且可用的 LinkSense 账号，不需要填写成员 ID。
- 企业代理、防火墙和 DNS 不应阻断渠道所需的出站连接。
- 只有 Teams 需要公网 HTTPS 回调；不要把密钥、二维码、配对码或回调密钥发送给他人排查。

## 连接和使用微信 [#weixin]

### 扫码连接 [#weixin-扫码连接]

1. 进入“设置 → 消息渠道”。
2. 在“微信”卡片选择“连接微信”。
3. 使用手机微信扫描二维码，并在手机上确认。
4. 如果手机显示配对码，在页面输入后提交。
5. 页面显示“在线”后即可关闭对话框。

二维码过期或连接失败时选择“重新生成”。已有连接需要恢复时，使用“重新连接”；新连接成功后会替换旧的运行连接。

### 支持范围 [#weixin-支持范围]

微信连接仅处理扫码账号本人发送的文本和可转写语音。其他账号、群聊或当前未支持的消息类型不会作为 LinkSense 请求执行。每条可处理消息会进入该用户自己的任务空间，并继续受模型、能力、知识库、并发和 credits 额度限制约束。

### 断开连接 [#weixin-断开连接]

选择“断开连接”并确认后，LinkSense 会停止接收和回复微信消息。已经创建的任务、消息和成果仍保留，可继续在 Web 端查看。

### 无法连接或没有回复 [#weixin-无法连接或没有回复]

- 确认二维码仍在有效期内，并完成手机上的确认或配对码步骤。
- 查看渠道状态是否为“在线”；“连接中”“连接异常”或“需要重新连接”时先重新连接。
- 确认消息来自扫码账号本人，并使用受支持的文本或语音。
- 检查账号 credits 额度、系统维护状态和任务并发限制。
- 多次重试仍失败时，将可见状态和发生时间提供给管理员，不要发送二维码、配对码或登录凭据。

## 连接和使用飞书 [#feishu]

连接飞书后，你可以在飞书中私聊机器人，将文本消息交给 LinkSense 处理，并在同一私聊中收到最终回复。

### 扫码连接 [#feishu-扫码连接]

1. 进入“设置 → 消息渠道”。
2. 在飞书卡片中选择“扫码创建机器人”。
3. 使用飞书扫描二维码并确认授权。
4. 等待页面显示连接成功，然后在飞书中打开新创建的机器人并发送文本消息。

LinkSense 会自动创建飞书官方机器人并保存连接所需的信息，无需手动填写应用凭据或配置回调地址。

再次扫码时，LinkSense 会优先更新已关联的飞书应用，不会为同一账号重复创建应用。如果上一次已经在飞书中创建成功、但 LinkSense 未完成关联，请按弹窗提示选择已经创建的应用继续连接。

### 等待管理员审核 [#feishu-等待管理员审核]

部分企业要求管理员审核新应用或权限。此时消息渠道会显示“等待管理员审核”或类似状态：

- 不需要反复扫码。
- 管理员批准后，LinkSense 会自动检测审核结果并恢复连接，通常几秒内即可更新。
- 审核期间机器人可能暂时无法收发消息。

若管理员已经批准但状态长时间未更新，请刷新消息渠道页面，并确认飞书应用仍然存在且所需权限没有被撤回。

### 支持范围 [#feishu-支持范围]

- 仅接收机器人创建者发送的一对一私聊文本消息。
- 每条有效消息会创建或继续一个私有 LinkSense 任务，并启动一次处理。
- 飞书中只返回最终文本结果；完整过程、工具调用和文件结果请在 LinkSense 任务中查看。
- 暂不处理群聊、其他成员私聊、图片、文件、语音、卡片或主动推送。

### 本地部署能否使用 [#feishu-本地部署能否使用]

可以。飞书连接由 LinkSense 所在电脑或服务器主动访问飞书，不要求把 `localhost` 暴露到公网，也不需要配置公网回调地址。

请确保运行 LinkSense 的环境可以向飞书发起 HTTPS 和 WebSocket 连接。企业代理、防火墙、DNS 或 TLS 拦截都可能导致页面看似已连接，但机器人收不到消息或无法回复。

### 飞书提示“应用不存在” [#feishu-飞书提示应用不存在]

如果原飞书应用已经被删除，不要继续扫描指向旧应用的二维码：

1. 关闭当前二维码弹窗并重新进入飞书连接。
2. 选择“应用已被删除？创建新应用”或页面提供的同类入口。
3. 扫描新二维码并完成授权。

新应用连接成功后会替换失效关联，之后再次扫码将继续更新这个应用。

### 断开连接 [#feishu-断开连接]

断开后，LinkSense 会停止接收该机器人的新消息。飞书中的官方应用和已经创建的 LinkSense 任务都会保留；以后重新连接时，LinkSense 会优先复用并更新原应用。

如果你还想删除飞书中的应用，请在飞书管理后台单独处理。删除后再次连接时，应使用“创建新应用”入口。

### 消息没有响应 [#feishu-消息没有响应]

依次检查：

1. 消息渠道状态是否已连接，而不是等待管理员审核或需要重新连接。
2. 是否由创建机器人的本人，在一对一私聊中发送纯文本。
3. 飞书应用是否仍存在，且管理员没有撤回已批准的权限。
4. LinkSense 所在环境是否可以访问飞书的 HTTPS 和 WebSocket 服务。
5. 刷新消息渠道页面，等待几秒后再发送一条简短文本；不要连续重复发送同一条消息。

### 出现“未命名任务”但没有启动 [#feishu-出现未命名任务但没有启动]

任务刚创建时可能短暂显示“未命名任务”。如果它一直为空且没有开始处理：

1. 打开该任务并刷新页面，确认原消息是否已经到达。
2. 回到消息渠道确认飞书仍为已连接状态。
3. 在同一机器人私聊中发送一条新的简短文本，避免重复发送原消息。
4. 如果仍然复现，请记录发生时间、飞书消息发送者和页面显示的稳定错误信息后联系管理员；不要提供二维码、应用凭据或敏感消息内容。

更多通用检查请参阅[常见问题排查](../troubleshooting/common-problems.mdx)。

## 连接和使用企业微信 [#wecom]

### 管理员配置 [#wecom-管理员配置]

1. 在企业微信创建企业内部智能机器人，选择 API 模式和长连接，并将机器人开放给需要使用的成员。
2. 在 LinkSense 进入“管理 → 系统设置 → 组织消息渠道”，选择“连接企业微信”。
3. 填写机器人 ID 和密钥，按需允许群内 @ 消息，保存配置并等待连接上线。无需指定某一个允许使用的成员。

机器人由管理员统一维护。管理员可以暂停、启用或断开连接；普通成员无需获取或填写机器人的密钥。暂停时保留成员关联和已有任务。

### 成员开始使用 [#wecom-成员开始使用]

1. 登录自己已注册且可用的 LinkSense 账号，进入“设置 → 消息渠道”。
2. 在企业微信卡片上选择“关联我的账号”，获取确认消息。
3. 将完整确认消息发送给企业微信机器人（私聊）。确认消息 10 分钟内有效，只能使用一次，请勿转发给他人。
4. 页面显示“账号已关联”后，私聊发送文本，或在已允许的群内 @ 机器人发起任务。

任务使用发消息成员本人的 LinkSense 权限、资源和额度。未注册、已停用或尚未关联的账号无法发起任务。同一群中不同成员的任务上下文分别保存；群内回复仍对群成员可见。

### 支持范围与排查 [#wecom-支持范围与排查]

当前支持内部成员的文本私聊和群内 @ 文本，不支持企业微信客户消息、图片、文件、语音和卡片。

未显示可用渠道时，请联系管理员完成配置或启用。连接异常时由管理员检查机器人信息、可见范围和网络。需要解除本人身份关联时，在消息渠道页选择“解除账号关联”。

更换机器人或密钥时，由管理员断开并重新配置；成员需要重新关联。断开会移除该连接的关联和待收发消息，已有 LinkSense 任务保留。

## 连接和使用钉钉 [#dingtalk]

### 扫码连接 [#dingtalk-扫码连接]

1. 登录已注册且可用的 LinkSense 账号，进入“设置 → 消息渠道”。
2. 在钉钉卡片上选择“扫码连接”，等待二维码生成。
3. 使用手机钉钉扫码，按钉钉页面提示创建并授权机器人。无需手动填写应用账号、密钥或成员 ID。
4. 授权成功后选择“关联我的账号”，获取确认消息，并将完整消息发送给机器人（私聊）。确认消息 10 分钟内有效，只能使用一次，请勿转发给他人。
5. 页面显示“账号已关联”后，即可向机器人发送文本任务。

钉钉机器人属于当前 LinkSense 用户，其他人不能通过该机器人使用你的账号。注册或扫码授权本身不会替其他人创建 LinkSense 账号。

### 使用范围 [#dingtalk-使用范围]

支持本人私聊文本，以及群内 @ 机器人的文本。每个聊天继续对应的任务，任务使用本人的权限、模型、能力和额度。群内回复对群成员可见。图片、文件、语音和卡片暂不支持。

### 无法连接或使用 [#dingtalk-无法连接或使用]

二维码过期或授权未完成时，重新生成二维码。请确认已完成钉钉页面要求的授权和组织审批，且网络允许访问钉钉。

未关联账号时，先到 LinkSense 获取确认消息并私聊发送。账号未注册、已停用、无可用模型或额度不足时，不能正常发起任务；按提示处理或联系管理员。

### 解除关联或断开 [#dingtalk-解除关联或断开]

“解除账号关联”会停止该钉钉身份使用 LinkSense，之后可以重新关联。“断开钉钉”会移除连接、成员关联和待处理的渠道消息，已有 LinkSense 任务会保留，钉钉平台上的机器人也会保留。

## 连接和使用Microsoft Teams [#teams]

### 管理员配置 [#teams-管理员配置]

1. 在 Microsoft Entra 注册公共云单租户应用并创建客户端密钥；创建使用相同应用 ID 和租户的 Azure Bot，启用 Microsoft Teams 渠道。
2. 在 LinkSense 进入“管理 → 系统设置 → 组织消息渠道”，选择“连接Microsoft Teams”。填写应用 Client ID、应用密钥和租户 ID，按需允许群内 @ 消息并保存。无需填写成员 ID。
3. 复制保存后显示的“消息接收地址”，将其设置为 Azure Bot 的消息传送终结点。该地址必须能通过公网 HTTPS 访问。
4. 创建包含该机器人的 Teams 应用包，按需配置个人、群聊和团队使用范围，并由组织管理员审批、安装或分发给成员。

管理员统一维护连接，可以暂停、启用或断开。普通成员无需配置应用凭据，也无需为了关联账号授予通讯录读取权限。Teams 登录配置与消息机器人配置分别管理。

### 成员开始使用 [#teams-成员开始使用]

1. 登录自己已注册且可用的 LinkSense 账号，进入“设置 → 消息渠道”。
2. 在 Microsoft Teams 卡片上选择“关联我的账号”，获取确认消息。
3. 将完整确认消息发送给 Teams 机器人（私聊）。消息 10 分钟内有效，只能使用一次，请勿转发给他人。
4. 显示“账号已关联”后，可以私聊发送文本，或在已允许的群聊、频道中 @ 机器人。

任务使用发消息成员本人的 LinkSense 权限、资源和额度。未注册、已停用或未关联的账号无法发起任务。同一群中不同成员分别保存任务上下文，频道内还按帖子继续任务。群内回复对群成员可见。

### 支持范围与排查 [#teams-支持范围与排查]

当前支持文本，不支持图片、文件、语音和卡片。只有本机可访问的地址无法接收 Teams 消息。

连接或回复异常时，由管理员检查应用 ID、租户、密钥、Teams 应用范围、组织审批、公网 HTTPS 地址和网络。成员可在消息渠道页解除本人账号关联。

更换应用或密钥时，由管理员断开并重新配置；成员需要重新关联。断开会移除该连接的关联和待收发消息，已有 LinkSense 任务保留。
