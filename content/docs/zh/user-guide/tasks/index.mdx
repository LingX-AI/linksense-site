从写清要求开始，继续了解执行控制、文件交付和任务整理。同一工作可以在一个任务中持续完善，无需反复新建任务。

## 创建与运行任务 [#create-and-run]

### 写出可执行的要求 [#create-and-run-写出可执行的要求]

一条有效请求通常包含：

- 目标：最终要解决什么问题。
- 输入：需要阅读的文件、数据或知识库。
- 约束：语言、格式、篇幅、时间范围或必须遵循的规则。
- 交付物：只需回答，还是需要 Word、Excel、PPT、PDF、图片或压缩包。

### 选择模型与推理强度 [#create-and-run-选择模型与推理强度]

点击输入框底部的模型与推理强度按钮，打开选择卡片。左右拖动滑条可预览不同强度，松手后保存；也可以点击滑条上的位置，或用键盘方向键调整。滑条只显示当前模型支持的档位。

点击卡片顶部的模型名称可切换模型，右上角的重置按钮可恢复当前模型的默认推理强度。切换模型时会保留可用的强度；如果新模型不支持该强度，则使用新模型的默认值。

模型选择器只显示管理员设为“对话可选”的对话模型。模型和推理强度在每个新轮次开始时确定；管理员后续修改配置不会重写已经运行或历史轮次。

如果原模型不再“对话可选”，页面会要求重新选择或使用对话默认模型。

模型卡片中的圆环会显示当前任务的背景信息窗口用量。接近上限时，先完成当前轮次，再按[草稿与上下文管理](#context-and-drafts)压缩上下文。

### 添加能力 [#create-and-run-添加能力]

在发送前可以：

- 选择已安装且启用的插件或 Skill。
- 选择你有权使用的知识库。
- 查看个人 MCP 的连接状态。

所选资源只对本轮固化。能力被停用、凭据缺失或知识库权限失效时，启动前检查会阻止执行并给出可处理的提示。

如果更适合口述，可以使用[语音输入](#voice-input)把麦克风语音转成可编辑草稿；确认文字后仍需由你主动发送。

管理员已启用图片生成模型时，也可以直接要求[生成图片](#generate-images)，结果会登记为任务成果。

### 使用目标模式完成长任务 [#create-and-run-使用目标模式完成长任务]

如果一条请求不是一次回复就能完成，可以使用[目标任务](#goal-tasks)。选择“+”，再选择“目标”，写清可衡量的结果，然后像普通任务一样添加附件、插件、Skill 或知识库。

目标任务会在用户消息下方显示目标标记，并在执行期间显示目标卡片。完成后，最终回复下方会显示达成目标的用时。

### 先规划再实施 [#create-and-run-先规划再实施]

需要先确认范围、风险和实施步骤时，选择“添加 → 计划模式”。LinkSense 会先分析需求、按需提出澄清问题，并在方案完成后等待你选择实施、修改、跳过或退出。具体行为见[使用计划模式](#plan-mode)。

输入 `/` 可以快速打开新任务、压缩上下文、插件、Skill、应用、知识库和 MCP 等功能入口；最终是否可用仍取决于当前任务状态和你的资源权限。

### 运行控制 [#create-and-run-运行控制]

- “停止”会请求中断当前运行。
- 网络短暂断开后，页面会尝试恢复同一轮次，而不是创建重复轮次。
- 页面刷新后可重新进入最近任务查看当前状态。
- 执行动态会显示计划、工具操作和状态变化；任务概览集中显示子智能体、成果文件和外部来源。详见[查看任务进度、成果与来源](#progress-and-sources)。
- 任务失败时，先阅读页面错误提示；调整输入或缺失配置后再重新发送。

<Callout type="info" title="任务与轮次">

一个任务可以包含多轮请求。继续对话会创建新轮次，但刷新、重连和同一轮的事件重投不会产生额外轮次。

</Callout>

## 草稿与上下文管理 [#context-and-drafts]

### 未发送草稿 [#context-and-drafts-未发送草稿]

LinkSense 会在当前浏览器中尽力保留输入框文字，以及已选择的插件、Skill 和知识库。离开页面后返回同一任务或新任务输入区时，可以继续编辑。

草稿不会在设备或浏览器之间同步，也不能替代正式保存。清理浏览器站点数据、使用隐私模式或浏览器存储空间不足时，草稿可能丢失。请求成功发送后，对应草稿会被清除；尚未完成上传的附件不属于这份本地草稿。

粘贴很长的文本时，LinkSense 可能把内容转换为附件，以保持输入区易于编辑。发送前可以在附件列表中确认或移除。

### 查看背景信息窗口 [#context-and-drafts-查看背景信息窗口]

模型选择器中的圆环会显示当前任务已使用的背景信息窗口比例。展开后可以查看已用量与总量；如果模型尚未报告用量或管理员未配置上下文长度，页面会显示“暂无上下文用量”。

背景信息窗口接近上限时，LinkSense 会根据已知的模型上下文长度让运行环境自动压缩工作上下文，执行动态中会显示压缩状态。模型长度未知或仍需要主动整理时，可以先完成当前轮次，再手动压缩。

### 压缩上下文 [#context-and-drafts-压缩上下文]

在一个已停止且未归档的现有任务中，输入 `/` 并选择“压缩上下文”，也可以直接发送独立命令 `/compact`。运行中、尚无历史或已归档的任务不能压缩。

手动压缩会让模型把已有运行上下文整理为更短的继续工作依据，不会删除页面中可见的消息历史、附件或成果。页面会显示“正在压缩上下文”“上下文已压缩”或“上下文压缩未完成”。压缩完成后再提交后续要求。

### 上下文超限时 [#context-and-drafts-上下文超限时]

普通任务仅因模型背景信息窗口超限而停止时，LinkSense 会尝试在同一个用户请求中继续一次，并要求模型沿用已经保存的任务与工作区状态，不重复已完成的命令、文件修改或工具操作。这不是一条新的用户请求。

如果恢复仍然失败，阅读页面错误后压缩上下文，再明确说明要从哪里继续。不要连续重复发送同一请求，以免重复外部操作或产生额外费用。

相关操作见[创建与运行任务](#create-and-run)和[运行中请求与排队](#running-requests)。

## 使用计划模式 [#plan-mode]

计划模式适合需求复杂、实施代价较高，或需要先统一范围再修改文件的任务。它与[目标任务](#goal-tasks)不同：计划模式先形成方案并等待确认；目标任务会持续执行，直到目标完成或需要你处理。

### 开启计划模式 [#plan-mode-开启计划模式]

在任务输入区选择“添加 → 计划模式”，描述目标、现状、约束和验收标准后发送。计划模式会显示为输入区中的“计划”标记，移除标记即可在发送前退出。

已经有运行中请求、排队请求、未结束目标或绑定自动化的任务不能切换计划模式。交互式应用等受控入口也可能不提供该模式。

### 回答澄清问题 [#plan-mode-回答澄清问题]

LinkSense 可以在形成方案前请求你补充信息。按表单填写必填项并提交后，原执行会继续；标为敏感的输入不会在任务界面中回显。问题可能有处理时限，过期后需要重新发起。

### 审阅方案 [#plan-mode-审阅方案]

方案完成后可以选择：

- “是，实施此计划”：退出计划模式，并按已确认方案开始新的实施轮次。
- “否，先修改计划”：填写修改意见，保持计划模式并生成一份完整的新方案。
- “跳过”：暂不处理，继续保持计划模式。
- “退出计划模式”：不实施当前方案，回到默认模式。

确认前请检查范围、文件变更、依赖、风险和验证方式。方案已经失效或任务状态发生变化时，页面会拒绝旧操作；刷新后以当前状态为准。

### 查看实施进度 [#plan-mode-查看实施进度]

实施过程中，任务概览会展示计划步骤、当前步骤、文件变化、成果和子智能体活动。步骤状态来自实际执行过程，不表示每个中间结果都已经通过你的业务验收。

## 使用目标任务 [#goal-tasks]

目标任务适合需要持续推进的工作，例如制作一套 PPT、整理长文档、查找资料并生成交付物，或把一个复杂任务分成多步完成。

开启目标后，LinkSense 会围绕同一个目标持续执行，直到目标完成、达到限制，或需要你补充信息。普通消息在发送时不会默认开启目标；你可以在发送前选择“目标”，LinkSense 也可能在执行普通任务时为需要持续推进的工作创建目标。

### 开启目标 [#goal-tasks-开启目标]

1. 在输入框左下角选择“+”。
2. 在能力菜单中选择“目标”。
3. 确认输入框左下角出现“目标”标记。
4. 写清希望 LinkSense 完成的目标。
5. 按需添加附件、插件、Skill、知识库、模型和推理强度。
6. 发送任务。

悬停在输入框里的“目标”标记上，可以退出目标模式。退出后发送的内容会按普通任务处理。

### 执行中创建目标 [#goal-tasks-执行中创建目标]

当普通任务需要持续执行多个步骤时，LinkSense 可以在执行过程中创建目标。当前任务会直接进入目标状态并显示目标卡片，不会重新提交你的请求或生成第二条用户消息。

后续步骤会继续出现在同一任务中。目标完成、达到限制或需要你处理时，界面会按普通目标任务显示对应状态；目标自动继续不会重新提交你的原始请求或重放已经完成的工具操作。

### 写清可达成的目标 [#goal-tasks-写清可达成的目标]

目标越具体，LinkSense 越容易判断是否完成。建议说明：

- 结果：最终需要交付什么，例如文章、表格、PPT、分析报告或压缩包。
- 范围：需要阅读哪些资料、时间范围、主题边界或数据来源。
- 标准：篇幅、语言、格式、页数、质量要求或必须包含的内容。
- 停止条件：什么情况算完成，什么情况需要先向你确认。

示例：

> 根据附件中的产品资料，制作一份 10 页中文路演 PPT，包含产品定位、核心功能、客户价值、竞品对比和下一步计划，并生成可下载文件。

### 搭配能力和附件 [#goal-tasks-搭配能力和附件]

目标任务可以像普通任务一样使用附件、插件、Skill、知识库和个人 MCP。发送前选中的能力会作为这次目标任务的上下文使用。

如果目标执行过程中需要补充新的材料或重新指定能力，可以在当前任务中继续发送请求。包含新附件或能力选择的请求会按执行中请求规则排队，避免打断正在运行的上下文。

### 查看目标状态 [#goal-tasks-查看目标状态]

目标消息会在用户消息右下角显示目标图标和“目标”标记，方便回看时区分普通请求和目标任务。

目标运行时，输入框上方会显示目标卡片。卡片会展示当前状态、目标内容和已用时间；点击时间可以查看目标详情，包括已用时间、已用 Token 和 Token 预算。

目标详情中的 Token 预算是目标自身的执行预算；管理员设置的个人 credits 额度是账号级设置，用于判断你是否还能发起新任务。两者独立生效。

目标完成后，目标卡片会消失，最终回复下方会显示“已在一段时间内达成目标”的完成标记。

### 暂停、恢复和清除 [#goal-tasks-暂停恢复和清除]

- 编辑目标：修改目标描述，已用时间和 Token 会保留。
- 暂停目标：停止目标的后续自动继续；如果当前轮次已经在执行，它可能会先自然完成。
- 恢复目标：让已暂停、需要处理或达到限制后的目标继续推进。
- 清除目标：从任务中移除目标状态和用量记录；这不会强制停止当前正在执行的原生轮次。

如果你希望立刻停止当前正在执行的轮次，请使用任务的“停止”操作。暂停目标和停止当前轮次是两个不同操作。

### 常见状态 [#goal-tasks-常见状态]

| 状态 | 含义 |
| --- | --- |
| 进行中的目标 | LinkSense 正在围绕目标自动推进。 |
| 已暂停的目标 | 目标不会继续自动执行，除非你恢复它。 |
| 需要处理的目标 | LinkSense 需要你的输入、外部变更或确认。 |
| 用量受限 | 当前用量限制阻止目标继续执行。 |
| 预算受限 | 目标达到已配置的 Token 预算。 |
| 已完成 | LinkSense 已将目标标记为完成。 |

## 使用项目整理任务 [#projects]

项目把相关任务和文件放在一起。同一项目中的任务共用项目文件；没有加入项目的个人任务共用一个公共工作区。插件、Skills、工具和个人登录状态在你的个人任务之间共用。

### 创建和使用项目 [#projects-创建和使用项目]

1. 点击侧边栏“项目”旁的 **+**，输入名称并创建。
2. 新建任务时，从输入框上方选择项目。
3. 发送消息开始工作。项目中的其他任务可以继续使用这里的文件。

每个任务最多属于一个项目。你可以展开或收起项目，拖动项目调整顺序，也可以置顶任务。项目名称和任务归属会保存到账号，展开状态保存在当前浏览器。

新建的应用开发任务统一归入 **制作应用**。首次创建时，如果你还没有这个项目，系统会自动创建；同名项目会直接复用。该项目可以更换图标和颜色，名称固定。已有的开发任务保留原项目和工程；应用预览、测试和日常使用任务不受此归类规则影响。

### 编辑名称、图标和颜色 [#projects-编辑名称图标和颜色]

在项目的 **…** 菜单中选择 **编辑**。点击名称左侧的图标，先选择颜色，再从图标网格中选择图案。点击 **完成** 返回编辑弹窗，再点击 **保存**。名称、图标和颜色会一起保存，并显示在侧边栏及项目选择器中；点击 **取消** 则放弃本次修改。新建项目时也可以设置图标和颜色。

已有项目默认使用文件夹图标。未加入项目的任务显示在 **最近** 下，置顶任务仍显示在 **置顶** 下。

### 移动任务 [#projects-移动任务]

拖动任务到目标项目，或使用任务菜单中的“移动到项目”。任务停止运行后才能移动；有排队消息、等待处理的计划或正在推进的目标时，需要先结束这些工作。

应用开发任务不能移动到其他项目，也不能移出所属项目；仍可置顶、归档和在原分组内排序。项目仍关联应用开发内容时，需要先在“我的应用”中删除相关应用，再移除项目。

移动后，新消息使用目标项目的文件。原项目文件会留在原处，历史消息中的附件仍可打开。已经上传但尚未发送的附件也会保留。

从回复创建分支时，新任务继承所属项目，共用项目文件。两个任务仍有各自的消息记录。

### 删除任务或移除项目 [#projects-删除任务或移除项目]

删除任务会删除该任务的消息记录，保留项目文件。选择 **移除项目** 会把任务移回公共工作区，保留原项目文件和历史附件。需要清理文件时，请单独处理文件。

在线应用服务拥有自己的工作环境。把应用任务放进项目只用于整理任务，不会把在线应用服务的文件或登录状态放进个人工作区。

### 运行环境与历史文件 [#projects-运行环境与历史文件]

你的任务使用同一个个人运行环境。空闲一段时间后，系统会停止环境以节省资源，文件和个人设置仍然保留。下次使用时会自动启动。正在执行任务或运行网站、服务时，环境不会因空闲而停止。

升级前的任务文件会保存在对应项目的 `imports/任务编号` 文件夹中，方便继续查看和使用；历史附件仍可从消息记录打开。

## 查看任务进度、成果与来源 [#progress-and-sources]

### 执行动态 [#progress-and-sources-执行动态]

运行中的任务会按时间显示可见的执行动态，例如思考进度、计划、工具操作、上下文压缩和状态变化。展开条目可以查看 LinkSense 允许展示的详情；涉及密钥、内部地址或受保护数据的内容会被隐藏。

网络重连、页面刷新或同一轮事件重新投递会继续同一轮次，不代表任务自动执行了第二次。历史较长时，页面会分批加载更早的问答；滚动或选择历史分组即可继续查看。

### 任务概览 [#progress-and-sources-任务概览]

任务顶部的概览入口集中显示：

- 子智能体及其当前状态和完成数量；
- 已登记的成果文件，可直接预览或下载支持的类型；
- 助手回复中识别出的外部网页来源。

没有使用子智能体、没有生成文件或没有外部来源时，对应区域会显示为空。执行计划和工具细节以消息下方的执行动态为准。

### 外部来源与知识库引用 [#progress-and-sources-外部来源与知识库引用]

“来源”列表会整理助手回复中的外部网页链接并去重。选择来源会在新窗口打开原网页；网页标题不可用时会显示网址。来源列表只帮助你回到原页面，不代表 LinkSense 对外部内容作额外背书。

知识库引用使用回复中的编号标记，并可打开引用片段或原文位置，和外部网页来源是两套不同入口。详见[使用知识库与查看引用](../knowledge-bases/index.mdx#use-and-citations)。

### 核对重要结果 [#progress-and-sources-核对重要结果]

- 检查结论是否与来源和附件一致。
- 对会影响财务、法律、医疗、安全或生产系统的决定，打开原始来源复核。
- 下载重要成果并保存到组织批准的位置；临时下载地址不能作为永久分享链接。

成果预览与下载见[文件、预览与成果](#files-and-results)。

## 文件、预览与成果 [#files-and-results]

### 添加附件 [#files-and-results-添加附件]

在任务输入区选择附件并等待上传完成，再发送请求。常见办公文档、PDF、文本、图片、表格、演示文稿和压缩包可作为任务材料；实际大小和类型限制以页面提示及部署配置为准。

在提示中明确指出文件名和处理目标，尤其是一次上传多个文件时。

粘贴很长的文本时，LinkSense 可能把内容转换为文本附件。发送前先确认附件名称和内容；这类附件与手动上传文件一样受大小、权限和安全限制约束。

### 预览文件 [#files-and-results-预览文件]

受支持的附件和成果可以在任务内预览。图片、PDF、Word、表格、演示文稿、HTML、压缩包、文本以及受支持的音视频会提供与格式相应的分页、缩放、工作表、幻灯片、文件列表或播放操作。若格式不能安全预览，仍可在有权限时下载原文件。

预览只用于查看，不会改变原文件。HTML 成果会在隔离的安全区域中显示，不能访问 LinkSense 主页面权限。

演示文稿、Word、Excel 和 HTML 预览支持选择具体内容并添加修改要求。可以累积多条后一次发送，详见[在文件预览中添加批注](#file-annotations)。

### 查看回复中的图表 [#files-and-results-查看回复中的图表]

助手回复中的 Mermaid 图表会在内容完整后渲染为适配当前明暗主题的图表预览。打开图表操作菜单可以复制 Mermaid 源码、导出 PNG，或展开后缩放和平移查看细节。流式回复尚未结束时会先显示加载状态，避免把不完整的代码当成最终图表。

图表渲染失败时，页面仍允许复制源码。可以把源码和错误现象发回当前任务，请 LinkSense 修正语法；导出的 PNG 是当前渲染结果，不会登记为新的任务成果。

### 下载成果 [#files-and-results-下载成果]

当 LinkSense 生成 Word、Excel、PPT、PDF、图片或其他文件时，文件会以成果卡片显示。选择下载后，系统签发短时有效的下载地址。

如果下载链接过期，从任务中再次选择下载即可；不要把临时下载地址当作永久共享链接。

HTML 成果还可以发布为无需登录即可访问的公开站点。发布、更新、停用和安全边界见[发布和管理站点](#publish-websites)。

### 集中查看任务产物 [#files-and-results-集中查看任务产物]

从侧边栏进入“资料库”，再选择“任务产物”标签页，可以按任务名称和生成时间查看当前账号任务中已登记的成果文件。选择支持的文件可沿用任务内预览器查看；任何列表文件都可以直接下载。已归档任务的产物仍会标注并保留在列表中。

搜索框会同时匹配任务名称和文件名。通过旁边的文件类型筛选，可以只查看图片、Word、Excel、PPT、HTML、PDF、压缩包、文本、音频、视频或其他文件。类型筛选可以与关键词搜索一起使用；选择“全部类型”即可取消类型限制。

选择任务名称可以返回原任务查看生成背景；任务被永久删除后，不再通过该列表访问其产物。

### 让结果更可用 [#files-and-results-让结果更可用]

- 明确文件类型和命名要求。
- 需要多个文件时说明目录或压缩包结构。
- 先检查预览，再要求修改。
- 重要成果下载后保存到组织批准的存储位置。

<Callout type="warn" title="敏感信息">

不要上传超出工作需要的密码、密钥、个人隐私或机密数据。插件和外部工具可能按其声明能力处理任务输入，请在使用前查看风险说明。

</Callout>

## 发布和管理站点 [#publish-websites]

LinkSense 可以把任务中已登记的 HTML 网页成果发布为公开站点。访问者不需要登录，任何获得链接的人都可以打开，因此发布前必须检查网页中是否包含敏感信息。

### 发布新站点 [#publish-websites-发布新站点]

1. 在任务中打开一个 HTML 成果的预览。
2. 选择预览工具栏中的“发布为站点”。
3. 选择“新建站点”，填写站点名称和可选简介。
4. 按需填写链接名称；留空时由 LinkSense 自动生成。
5. 选择“发布站点”，等待页面显示站点链接。
6. 复制链接并在未登录窗口中检查内容和交互。

同一 HTML 再次点击“发布为站点”时，会显示它已关联站点的当前链接和发布状态；也可以选择“更新其他站点”。

自定义链接名称只能使用 3–80 位英文字母、数字或连字符，不能以连字符开头或结尾。如果名称已被占用，请换一个名称。

网页可以包含成果登记时一同保存的 CSS、JavaScript、图片、字体和其他静态资源。只有单个 HTML 文件但引用了已丢失的本地文件时，发布会失败；请让 LinkSense 重新生成并登记完整网页成果。

### 更新已有站点 [#publish-websites-更新已有站点]

从新的 HTML 成果发布时，可以选择“更新已有站点”，搜索并选择你拥有的站点。更新成功后：

- 站点沿用原链接、名称和简介；
- 当前发布内容切换到新的网页成果；
- 来源任务更新为提供新网页的任务；
- 原本处于“未发布”的站点仍保持未发布，需要在“我的站点”中重新发布。

也可以进入“资料库 → 我的站点”，从站点菜单选择“更新发布”，再选择当前来源任务中的网页成果。来源任务已经删除时，请从新的任务成果发起“更新已有站点”。

### 管理我的站点 [#publish-websites-管理我的站点]

进入“资料库 → 我的站点”，可以搜索站点名称或链接，并按“已发布”或“未发布”筛选。

每个站点提供以下操作：

- **访问或复制链接**：打开当前公开版本，或把链接发送给其他人。
- **编辑**：修改名称、简介或链接名称。修改链接名称后，旧链接立即失效。
- **更新发布**：从来源任务的 HTML 成果中选择一个新版本。
- **取消发布／重新发布**：控制访客是否能访问；取消发布会保留站点、链接占用和已保存版本。
- **下载网页包**：下载当前版本的完整 ZIP，便于留档或迁移。
- **删除站点**：永久删除站点、全部发布版本和链接占用。原任务与原始成果仍会保留，删除后的链接名称可以被重新使用。

永久删除来源任务时，关联站点会自动变为“未发布”，但已保存的站点版本仍可在“我的站点”中下载。以后可以从其他任务生成新网页，选择“更新已有站点”重新关联并发布。

### 公开访问与安全边界 [#publish-websites-公开访问与安全边界]

公开站点运行在隔离区域中，不能读取 LinkSense 的登录 Cookie、本地存储或父页面，也不能注册 Service Worker。它适合静态网页和浏览器内交互，不会运行服务端程序，也不会继承你的 LinkSense 权限。

外部 HTTPS 资源由访问者的浏览器直接加载，仍受资源可用性和跨域规则影响。站点不能依赖 LinkSense 登录态、服务器路由回退或浏览器持久化同源存储。发布前请确认：

- 页面及其静态资源能够完整加载；
- 没有密码、Token、个人隐私、内部地址或不应公开的任务内容；
- 表单和外部请求不会把数据发送到不可信服务；
- 取消发布、修改链接或删除站点后，旧链接的行为符合预期。

任务成果的预览、下载和集中管理见[文件、预览与成果](#files-and-results)。

## 在文件预览中添加批注 [#file-annotations]

文件批注用于把“修改哪里”和“怎么修改”一起交给 LinkSense，适合审阅演示文稿、Word、Excel 和 HTML 成果。批注会形成新的任务请求，不会直接在浏览器中改写原文件。

### 添加批注 [#file-annotations-添加批注]

1. 在任务中打开受支持的文件预览。
2. 选择“添加标注”或进入标注模式。
3. 选中幻灯片元素、Word 内容、工作表区域/图表/图片，或 HTML 元素。
4. 输入问题或修改要求，选择“添加标注”。
5. 继续选择其他位置，或打开“待发送标注”检查列表。

每批最多保留 20 条标注。列表会显示页码、幻灯片、工作表或元素位置；可以定位、移除单条或清空全部。

### 批量处理 [#file-annotations-批量处理]

确认后选择“全部处理”。LinkSense 会把同一文件中的剩余标注合并为一次请求，并保留各条选区与要求的对应关系。发送失败时草稿会继续保留，可修正网络或任务状态后重试。

切换到另一个文件会清除当前文件尚未发送的标注。发送前先确认文件和选区，尤其是在预览提示内容已更新时。

### 查看历史批注 [#file-annotations-查看历史批注]

已发送批注会作为用户消息卡片保存在任务中。选择卡片可以重新打开对应文件和位置。若原任务或文件已被永久删除，历史卡片不能恢复文件内容。

## 生成图片 [#generate-images]

管理员配置并启用图片生成模型后，可以在普通任务中直接描述希望生成的图片。LinkSense 会选择内置图片生成能力，并把成功生成的图片登记为任务成果。

### 写出清晰要求 [#generate-images-写出清晰要求]

建议说明：

- 主体：人物、产品、场景或图形元素；
- 风格：摄影、插画、3D、海报、图标等；
- 构图：视角、布局、留白、颜色和光线；
- 文字：需要准确出现的短文案及位置；
- 输出：图片数量、尺寸或横竖比例、是否需要透明背景。

例如：“生成一张 1024×1024 的极简产品图标，主体完整位于画布内，四周留白，透明背景，只生成 1 张。”未指定数量时通常生成一张；实际数量和尺寸还受当前服务商与模型限制。

### 编辑已有图片 [#generate-images-编辑已有图片]

上传图片后，直接说明要修改的部分，例如：“把这张照片的背景换成海边，保留人物、服装和姿势。”也可以继续要求修改上一轮生成的图片。LinkSense 会把原图与编辑要求一起交给当前图片模型，每次修改生成新的图片成果，原图不会被覆盖。

支持 PNG、JPEG 和 WebP，单张不超过 8 MiB，原图与可选蒙版合计不超过 10 MiB。最多可使用四张参考图，实际数量取决于模型；多图时请说明各图用途。局部编辑蒙版须为与首张原图同尺寸的透明 PNG，透明区域表示需要修改的部分。

图片编辑需要管理员配置支持编辑的模型。支持参考图的模型不一定支持蒙版；遇到不支持的要求时会明确提示，不会忽略原图改为纯文字生成。生成式编辑可能改变未指定的细节，请在下载使用前检查结果。

### 透明背景 [#generate-images-透明背景]

需要贴纸、图标、商品抠图或可叠加素材时，明确写出“透明背景”。简单且边缘清楚的主体可以自动处理；头发、毛发、玻璃、烟雾、发光和半透明材质需要模型原生支持高质量透明边缘。如果当前模型不支持，LinkSense 会显示限制，不会悄悄换成质量较差的结果。

### 查看结果与费用 [#generate-images-查看结果与费用]

生成完成后，等待区域会直接显示图片。同一轮生成多张图片时，左侧显示选中的大图，右侧显示缩略图，点击缩略图即可切换。点击大图可打开预览，鼠标移到大图上时会显示下载按钮；在触屏设备上可直接使用下载按钮。图片会按照内容和场景命名，一次生成多张图片会添加序号，也可以在“资料库 → 任务产物”集中查找。管理员按图片生成服务配置每张价格，实际生成张数会计入用量与 credits。

### 失败时 [#generate-images-失败时]

通过代码绘图或 SVG 渲染得到的图片，登记为任务成果后同样会显示在图片区域，支持预览、切换和下载。过程中查看过的参考图不会覆盖正式交付的图片。

- “尚未配置或未启用”：联系管理员完成图片生成模型设置。
- 服务商拒绝：检查提示词、模型或管理员配置，修改后再提交。
- 服务暂不可用：稍后再试。
- 透明背景不支持：改用支持原生透明的模型，或在边缘要求允许时选择普通背景。
- 页面提示结果登记或用量记录失败时，不要立即重复生成；服务商可能已经处理并计费，先联系管理员核对。

普通文件成果的预览、下载和临时链接规则见[文件、预览与成果](#files-and-results)。

## 使用语音输入 [#voice-input]

语音输入只负责把你说的话转换为输入框文字，不会自动提交任务，也不会把录音作为任务附件。

### 录制并转写 [#voice-input-录制并转写]

1. 在任务输入框或 Office 选区操作输入框中选择麦克风按钮。
2. 首次使用时，允许当前 LinkSense 页面访问麦克风。
3. 看到录音时长和波形后开始说话。
4. 选择停止按钮；录音达到 5 分钟时也会自动停止。
5. 等待“正在转写语音”结束。
6. 检查并编辑写入输入框的文字，再自行选择发送或执行操作。

转写期间不能重复开始录音或提交当前输入。已输入的文字会保留，转写内容会写入当前草稿。

### 录音限制 [#voice-input-录音限制]

- 录音必须至少持续 1 秒。
- 单次录音最长 5 分钟。
- 音频超过安全传输大小时，需要缩短后重新录制。
- 浏览器必须支持 `MediaRecorder`，并且设备存在可用麦克风。

Web 与 Teams 使用相同规则。系统只在当前录音和转写请求期间临时处理音频；原始录音不会作为附件保存到任务、文件存储、工作区、审计或日志。

### 无法使用时 [#voice-input-无法使用时]

- 权限被拒绝：在浏览器或 Teams 的站点权限中允许麦克风，再重试。
- 找不到设备：检查麦克风连接和系统输入设备。
- 设备被占用：关闭正在独占麦克风的应用后重试。
- 未识别到内容：靠近麦克风、减少背景噪声并重新录制。
- 转写超时或失败：稍后重试，或继续使用键盘输入。

<Callout type="warn" title="隐私提示">

录音会被发送到部署方配置的语音识别服务完成转写。不要朗读密码、密钥或超出工作需要的敏感信息。

</Callout>

## 执行中的补充请求 [#running-requests]

当当前轮次仍在运行时，你可以继续输入。LinkSense 会根据请求内容和“设置 → 常规”中的偏好决定处理方式。

### 引导当前执行 [#running-requests-引导当前执行]

“引导当前执行”适合纯文本的即时补充，例如：

- 只分析最近三个月。
- 优先输出结论，不需要背景介绍。
- 别继续生成 PPT，改为 Excel。

这类内容会追加到当前执行，不会另建一个并行轮次。

### 排队为下一条请求 [#running-requests-排队为下一条请求]

“排队”会保留当前执行，等其结束后自动开始新请求。以下情况始终需要排队：

- 请求包含新附件。
- 请求重新选择插件、Skill 或知识库。
- 内容需要在新的稳定上下文中执行。

排队中的请求会显示在任务中。启动前可以按页面提供的操作修改或撤销。

### 停止当前执行 [#running-requests-停止当前执行]

停止会请求中断当前轮次。已经产生的可见消息或成果可能仍保留，尚未完成的工具操作不保证生成可用结果。

### 设置默认行为 [#running-requests-设置默认行为]

进入“设置 → 常规 → 执行中发送新消息”，选择：

- 引导当前执行。
- 排队为下一条请求。

该设置同步到你的账号，在 Web 和 Teams 中使用。含附件或能力选择的请求仍会自动排队。

## 管理任务历史 [#manage-history]

### 最近任务 [#manage-history-最近任务]

左侧“任务”区域按最近更新时间显示未归档任务。滚动到底部时会继续加载。任务在后台完成且尚未查看时会显示未读状态，打开任务后即标记为已查看。

### 搜索任务 [#manage-history-搜索任务]

选择侧边栏“搜索”，可以匹配任务标题、消息、附件、成果、插件或 Skill。搜索结果只包含你有权访问的任务。

打开历史较长的任务时，LinkSense 会先显示最近内容，再分批加载更早的问答。需要引用或分享早期内容时，先把相应历史加载出来。

### 重命名与置顶 [#manage-history-重命名与置顶]

在任务操作中可以修改标题。置顶会让常用任务保持在列表前部；取消置顶后进入最近任务分组。置顶数量达到上限时，先取消一个旧任务。

置顶和最近任务均可在各自分组内拖动排序，也支持键盘操作；两个窗口同时更新顺序时，以服务端保存的最新版本为准。完整操作见[创建任务分支与调整顺序](#branch-and-organize)。

### 从历史回复继续不同方向 [#manage-history-从历史回复继续不同方向]

对已结束轮次的最终助手回复选择“分支到新聊天”，可以复制截至该回复的历史和运行上下文，形成一个不影响原任务的新任务。正在运行、存在排队请求或已归档的任务不能创建分支。

### 归档 [#manage-history-归档]

归档会把任务移出最近任务列表，但不会立即删除内容。进入“设置 → 已归档任务”可以查看、恢复或删除归档任务。

### 永久删除 [#manage-history-永久删除]

删除或清空归档任务是不可撤销操作。任务正文、附件和可恢复记录会按系统规则清理；为安全、审计和资源统计保留的最小活动、用量或成果元数据可能继续存在，但不能用来恢复任务内容。

<Callout type="info" title="整理建议">

置顶持续进行的工作，完成后归档；只有确认不再需要正文、附件和历史结果时才永久删除。

</Callout>

### 分享当前对话 [#manage-history-分享当前对话]

点击任务右上角“分享”，先查看弹窗中的预览，再选择“复制链接”。链接只包含这次预览中的消息和附件信息，不显示你的姓名；附件信息不提供公开下载。

预览在打开弹窗时固定，后续新增消息、继续生成的回答或对原内容的修改都不会加入本次分享。如果要分享更新后的内容，关闭弹窗后重新打开并复制新链接。新链接对应新的快照，旧链接保持不变。

分享预览不会自动加载尚未加载的历史消息。如需包含更早的对话，请先在原任务中加载相应历史，再打开分享弹窗。永久删除原任务后，其分享链接也会失效。

## 创建任务分支与调整顺序 [#branch-and-organize]

### 从回复创建分支 [#branch-and-organize-从回复创建分支]

在一个已经停止的任务中，找到要保留为分叉点的助手最终回复，选择消息操作中的“分支到新聊天”。LinkSense 会创建并打开一个新任务，复制截至该回复的对话、附件、成果、知识库引用以及可继续使用的运行上下文。

分支不会复制分叉点之后的内容，也不会修改原任务。新任务使用带序号的标题，初始为未置顶状态；此后两个任务的消息、文件和运行相互独立。

以下状态不能创建分支：

- 原任务仍在运行、正在启动或存在排队请求。
- 选中的回复不是某个已结束轮次的最终助手回复。
- 原任务已归档，或运行上下文暂时无法安全复制。

创建失败不会产生一个可见的半成品任务；确认原任务已经停止后再重试。

### 调整任务顺序 [#branch-and-organize-调整任务顺序]

可以在侧边栏分别拖动“置顶”和“最近”分组中的任务。任务只能在当前分组内排序；先置顶或取消置顶，再调整其所在分组的顺序。

使用键盘时，聚焦任务排序控件，按空格选中，使用上下方向键移动，再按空格保存；按 Escape 取消。若其他窗口同时改变了任务列表，保存可能被拒绝，刷新后重新排序即可。

### 与归档和删除的关系 [#branch-and-organize-与归档和删除的关系]

分支和原任务都是独立任务。归档或永久删除其中一个不会自动处理另一个。若分支保留了复制成果，请仍以各自任务中的下载入口和权限为准。
