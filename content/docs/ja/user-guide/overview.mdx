LinkSenseはタスクごとに整理されています。 タスクは会話、ファイル、成果物をまとめて管理しつつ、プラグイン、スキル、ナレッジベースを選択できます。

## 主なエリア [#main-areas]

| 面積 | 目的 |
| --- | --- |
| 新たな任務 | リクエストを提出し、モデル、プランモードまたは目標モード、機能を選択します |
| 自動化 | 1つの固定されたタスクで、1時間単位、毎日、週単位、または月単位で繰り返し作業を行ってください |
| プラグインセンター | プラグイン、スキル、MCP、アプリケーションの発見、インストール、更新、管理 |
| リソースライブラリ | ナレッジベースの管理、タスクの成果物の閲覧、公開サイトの公開や維持 |
| 舞台設定 | 言語、プロフィール、パーソナライズ、メッセージチャネル、セキュリティ、認証情報、MCPの管理 |
| フィードバックと助け | 現在のページのフィードバックを送信し、ヘルプを開く |

**リソースライブラリ**の項目には、複数の立った本を示すアイコンが使われています。 **ナレッジベース**は検索可能なドキュメントと共有を管理し、**タスクの成果物**タスクで生成されたファイルをまとめ、HTMLの成果物から公開された公開ページ**私のサイト**管理します。

## 推奨される最初のステップ [#recommended-first-steps]

1. サインインしてインターフェースの言語を確認してください。
2. 最初のタスクを作成し、その実行状況と結果を確認します。
3. 必要に応じてファイル、プラグイン、スキル、ナレッジベースを追加したり、LinkSenseに画像生成を依頼したりできます。
4. アクティビティやタスク概要を使って進捗、成果物、外部ソースを確認しましょう。
5. 結果をさらに洗練させてください。 長い履歴の場合は、コンテキストウィンドウの使用や必要に応じてコンパクトコンテキストをレビューしてください。
6. 複雑な作業にはプランモードを使い、過去の回答から分岐して別の方向性を試すこともできます。
7. 繰り返し作業のための自動化を作成したり、安定したワークフローを共有アプリケーションに変えたりしましょう。

## あなたのデータ境界 [#your-data-boundary]

- 自分のタスク、メッセージ、添付ファイル、納品物しか読めません。
- 共有知識ベースは閲覧・検索可能ですが、ドキュメントや共有を管理するのは所有者だけです。
- 個人プラグイン、スキル、認証情報、MCPサーバーはあなたのタスクにのみ使われます。
- 管理者はアカウントやプラットフォームの機能を管理しますが、監査UIは他のユーザーのタスクボディやファイルの内容を公開しません。
