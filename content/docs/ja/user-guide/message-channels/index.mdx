まずはサポートされている機能を比較し、その後、接続やトラブルシューティングの手順に従ってプラットフォームを進めてください。

## メッセージチャンネル概要 [#overview]

**設定 → メッセージチャネル**開いてLinkSenseをチャットプラットフォームに接続してください。 チャネルメッセージは引き続きプライベートのタスク空間で処理され、モデル、能力、並行性、クレジット限度額の対象となります。

### チャンネルを選びましょう [#overview-choose-a-channel]

| チャンネル | 接続方法 | サポートメッセージ | ネットワーク要件 |
| --- | --- | --- | --- |
| [偉心](#weixin) | 個人のWeixinアカウントでQRコードをスキャンしてください | リンクされたアカウントからのテキストと文字起こし可能な音声 | 公の場での折り返しはなかった |
| [飛書](#feishu) | QRコードをスキャンして公式ボットを作成または更新できます | ボット作成者からの一対一のテキスト | アウトバウンドHTTPSおよびWebSocket;公の場でのコールバックはありません |
| [WeCom](#wecom) | 管理者の設定の後、各メンバーがアカウントを連携します | リンクされたメンバーによるプライベートテキストとグループ@メンション | アウトバウンドHTTPSと長時間接続;公の場でのコールバックはありません |
| [ディングトーク](#dingtalk) | 個人用QRの作成と認証、そしてアカウント連携 | あなたのプライベートテキストとグループ@メンズ | ストリーム接続;公の場でのコールバックはありません |
| [Microsoft Teams](#teams) | 管理者管理のEntra/Azure Bot with with with member account linking | リンクされたメンバーからのプライベート、グループ、またはチャンネル@の言及 | 公開可能なHTTPSメッセージングエンドポイントが必要です |

チャンネルは各メンバーとチャットに対応するタスクを継続します。 組織ボットの異なるメンバーは、それぞれ異なるタスクコンテキストを持っています。 グループの返信は他の人にも見られる可能性があるため、非公開のままのコンテンツを送らないでください。

### 完全な結果を見る場所 [#overview-where-to-view-complete-results]

メッセージチャネルは主に最終テキストを返します。 ツールの活動、実行詳細、添付ファイル、生成ファイル、長い結果については対応するLinkSenseタスクに戻ってください。 代わりにウェブインターフェースからサポートされていないファイルやメッセージタイプを追加してください。

### 接続前に [#overview-before-connecting]

- ご自身のプラットフォームアカウントか、組織承認のボットアプリケーションを使用してください。
- WeCom、DingTalk、Teamsの各IDを、既存のアクティブなLinkSenseアカウントにリンクしてください。 メンバーIDの入力は必要ありません。
- エンタープライズプロキシ、ファイアウォール、DNSが必要なアウトバウンド接続をブロックしないようにしてください。
- 公開HTTPSコールバックが必要なのはTeamsだけです。 トラブルシューティング中に秘密情報、QRコード、ペアリングコード、コールバック認証情報を絶対に共有しないでください。

## 接続して魏心をご利用ください [#weixin]

### QRコードで接続 [#weixin-connect-by-qr-code]

1. **設定 → メッセージチャネル**に行け。
2. 魏心カードの**Weixin に接続**を選んでください。
3. 携帯でWeixinのQRコードをスキャンして確認してください。
4. もしスマホにペアリングコードが表示されたら、LinkSenseに入力して送信してください。
5. ステータスが**オンライン**になったらダイアログを閉じてください。

QRコードが期限切れになるか接続が失敗した場合は**再生成**を選びます。 既存の接続を復元するために**再接続**を使うこと;新しい接続が成功すると、古いランタイム接続が置き換えられます。

### 対応範囲 [#weixin-supported-scope]

Weixin接続は、コードをスキャンしたアカウントから送信されたテキストメッセージと文字起こし可能な音声メッセージのみを処理します。 他のアカウント、グループチャット、対応されていないメッセージタイプはLinkSenseリクエストを開始しません。 すべての受理されたメッセージはそのユーザーのタスク空間で実行され、モデル、能力、知識ベース、並行性、クレジット割当の対象となります。

### 切断 [#weixin-disconnect]

**接続を解除**を選択し、魏心のメッセージの受信と返信を停止することを確認してください。 既存のタスク、メッセージ、アーティファクトはウェブアプリ内で引き続き利用可能です。

### 接続または応答の問題 [#weixin-connection-or-reply-problems]

- QRコードが有効で、電話での確認またはペアリングコードの手順を完了していることを確認してください。
- ステータスが「**オンライン**」か確認してください。 それが**接続中**、**接続エラー**、または**再接続が必要です**になったら再接続してください。
- コードをスキャンしたアカウントからサポート可能なテキストメッセージや音声メッセージを送信してください。
- クレジットノルマ、定期メンテナンス、タスクの同時実行制限を確認してください。
- 再試行が失敗し続ける場合は、管理者に表示されたステータスと時間を伝えましょう。 QRコード、ペアリングコード、サインイン認証情報の共有はしないでください。

## 接続してフェイシュを活用してください [#feishu]

フェイシュに接続した後、プライベートチャットでボットにテキストを送ることができます。 LinkSenseはメッセージを処理し、同じチャット内で最終的な返信を返します。

### QRコードで接続 [#feishu-connect-by-qr-code]

1. **設定 → メッセージチャネル**開け。
2. フェイシュカードでは**ボットを作成するためにスキャン**を選択します。
3. フェイシュと一緒にQRコードをスキャンしてリクエストを承認してください。
4. ページに成功した接続が表示されるまで待ってから、Feishuの新しいボットを開いてテキストメッセージを送ります。

LinkSenseは公式のFeishuボットを作成し、接続に必要な情報を安全に保存します。 アプリケーションの認証情報を入力したり、コールバックURLを手動で設定したりする必要はありません。

再度スキャンすると、LinkSenseは同じアカウントの複製を作成するのではなく、関連するFeishuアプリケーションを更新します。 もしFeishuが以前の試みでアプリケーションを作成し、LinkSenseが関連付けを完了していない場合は、ダイアログに従って既存のアプリケーションを選択し、続行してください。

### 管理者の承認を待つ [#feishu-wait-for-administrator-approval]

一部の組織では、新しいアプリケーションや権限の承認に管理者が必要です。 チャンネルは**管理者の承認待ち**またはそれに類するステータスを表示します。

- 再度スキャンする必要はありません。
- 承認後、LinkSenseは自動的に変更を検知し、通常数秒以内に接続を回復します。
- 承認待ち中はメッセージの送受信ができない場合があります。

承認が完了してもステータスが長期間更新されない場合は、メッセージチャンネルページを更新し、Feishuアプリケーションがまだ存在し、必要な権限が取り消されていないかを確認してください。

### サポートメッセージ [#feishu-supported-messages]

- ボット作成者からの1対1のプライベートテキストメッセージのみが受け付けられています。
- 各受信メッセージはプライベートなLinkSenseタスクを作成または継続し、1回の処理ターンを開始します。
- フェイシュは最終的なテキスト結果のみを受け取ります。 LinkSenseタスクを開くと、進捗、ツールの活動、ファイル結果がすべて確認できます。
- グループチャット、他の人からのメッセージ、画像、ファイル、ボイスメッセージ、カード、積極的なプッシュは現在サポートされていません。

### ローカル展開での使用 [#feishu-use-with-a-local-deployment]

ローカル展開もサポートされています。 LinkSenseを動かすコンピュータやサーバーはFeishuに接続しているため、公開`localhost`公開したり、公開コールバックURLを設定したりする必要はありません。

LinkSense環境はHTTPSとWebSocketを通じてFeihuに届く必要があります。 企業プロキシ、ファイアウォール、DNSの問題、TLS傍受により、メッセージや返信が届かないままチャネルが接続されたように見えることがあります。

### フェイシュはその申請書は存在しないと言っています [#feishu-feishu-says-the-application-does-not-exist]

元のFeishuアプリケーションが削除されている場合、それを示すQRコードをスキャンし続けないでください。

1. 現在のQRダイアログを閉じて、Feihu接続を再開してください。
2. **申請が削除された? 新しいアプリケーションを作成する**またはページに表示されている同等のオプションを選択してください。
3. 新しいQRコードをスキャンして承認してください。

新しいアプリケーションが接続されると、無効なアソシエーションが置き換えられます。 後日スキャンでこのアプリケーションは更新されます。

### 切断 [#feishu-disconnect]

切断後、LinkSenseはボットからの新しいメッセージを受け取らなくなります。 公式のFeishuアプリケーションと既存のLinkSenseタスクは引き続き利用可能です。 再接続すると、LinkSenseはまず元のアプリケーションの再利用と更新を試みます。

Feishuからも申請を削除するには、Feishu管理で別途削除してください。 次に接続するときは**新しいアプリケーションを作成する**パスを使ってください。

### ボットは応答しません [#feishu-the-bot-does-not-respond]

以下の項目を順番に確認してください:

1. チャンネルは接続されており、管理者の承認や再接続のリクエストを待つことはありません。
2. ボット作成者は1対1のプライベートチャットでプレーンテキストを送信しています。
3. フェイシュの申請は依然として存在しており、その承認された許可は取り消されていません。
4. LinkSense環境はHTTPSとWebSocketを通じてFeihuに到達できます。
5. メッセージチャンネルページを更新し、数秒待ってから短いテキストメッセージを1回送信します。 繰り返しのコピーを提出しないでください。

### タイトルのないタスクが表示されますが、開始はしません [#feishu-an-untitled-task-appears-but-does-not-start]

新たに作成されたタスクは一時的に**無題のタスク**として現れることがあります。 もし空のままで、エンジンがかからない場合は:

1. タスクを開き、ページをリフレッシュして元のメッセージが届いたか確認します。
2. メッセージチャンネルに戻り、フェイシュがまだ接続されているか確認してください。
3. 同じボットチャット内で、元のメッセージを繰り返すのではなく、新しい短いテキストメッセージを送りましょう。
4. 問題が続く場合は、管理者に連絡する前にページに表示されている時間、Feisu送信者、安定エラーメッセージを記録してください。 QRコード、アプリケーションの認証情報、機密性の高いメッセージ内容の共有は禁止。

追加のチェックについては、[よくある問題のトラブルシューティング](../troubleshooting/common-problems.mdx)を参照してください。

## 接続してWeComをご利用ください [#wecom]

### 管理者設定 [#wecom-administrator-setup]

1. APIモードで長時間接続した内部WeComのインテリジェントボットを作成します。 アクセスが必要な会員に提供してください。
2. LinkSenseで**管理 → システム設定 → 組織のメッセージチャネル**を開き、**Connect WeCom**を選択します。
3. ボットIDと秘密を入力し、メンバーがグループ内でボットを言及できるかどうかを選んでセーブします。 接続がオンラインになるのを待ちましょう。 単一の会員制はありません。

管理者は接続を維持し、一時停止、有効化、切断が可能です。 メンバーはボットの認証情報を必要としません。 一時停止はアカウントの関連付けや既存のタスクを保持します。

### 会員アクセス [#wecom-member-access]

1. ご自身の既存の有効なLinkSenseアカウントにサインインし、**設定 → メッセージチャネル**を開きます。
2. WeComカードで**自分のアカウントを連携**を選択すると、確認メッセージが表示されます。
3. 完全なメッセージをWeComボットにプライベートチャットで送信してください。 有効期限は10分、使用は1回です。 他の誰にも転送しないでください。
4. ページに**アカウント連携済み**が表示されたら、プライベートテキストを送るか、許可されたグループでボットの名前を伝えてください。

タスクは送信者自身のLinkSense権限、リソース、ノルマを使用します。 未登録、無効、または連携解除されたアカウントはタスクを開始できません。 同じグループの異なるメンバーはそれぞれ異なるタスクコンテキストを持っています。グループ内の返信はメンバーに表示されます。

### 範囲とトラブルシューティング [#wecom-scope-and-troubleshooting]

メンバー内部のテキストメッセージやグループでの言及もサポートされています。 顧客メッセージ、画像、ファイル、音声、カードはまだサポートされていません。

管理者に利用できないチャネルの設定や有効化を依頼してください。 接続が失敗した際には、管理者はボットの認証情報、可視性、ネットワークアクセスを必ず確認すべきです。 メンバーはメッセージチャンネルページで**アカウント連携を解除**を選択できます。

ボットやその秘密を置き換えるために、管理者が切断して再度設定します。メンバーはその後、再びアカウントを連携します。 切断すると、既存のLinkSenseタスクは保持しつつ、関連付けとキューにされたチャネルメッセージが削除されます。

## 接続してDingTalkを利用しましょう [#dingtalk]

### QRコードで接続 [#dingtalk-connect-by-qr-code]

1. 既存のアクティブなLinkSenseアカウントにサインインし、**設定 → メッセージチャネル**を開きます。
2. DingTalkカードの**QR コードで接続**を選び、QRコードを待ちます。
3. スマートフォンのDingTalkでスキャンしてください。 DingTalkの手順に従ってボットを作成・承認してください。 申請資格や会員IDの入力は不要です。
4. 承認後、**自分のアカウントを連携**を選択し、確認メッセージを受け取り、完全なメッセージをボットにプライベートチャットで送信します。 有効期限は10分、使用は1回です。 他の誰にも転送しないでください。
5. ページに**アカウント連携済み**が表示されたら、ボットにテキストタスクを送信してください。

そのボットは現在のLinkSenseユーザーのものです。 他の人はこのアカウントを通じてあなたのアカウントを使えません。 ボットをスキャンまたは承認しても、他の人のLinkSenseアカウントは登録されません。

### サポートされた行動 [#dingtalk-supported-behavior]

このチャンネルは、ボットに関するプライベートテキストメッセージやグループテキストをサポートします。 各チャットは、あなたの権限、モデル、能力、ノルマを使って対応するタスクを継続します。 グループの返信はメンバーに表示されます。 画像、ファイル、音声、カードはまだサポートされていません。

### 接続やアクセスの問題 [#dingtalk-connection-or-access-problems]

QRコードが期限切れになったり、承認が完了しない場合は新しいQRコードを生成してください。 DingTalkの承認および組織承認要件を満たし、ネットワークがDingTalkに到達できるようにしてください。

アカウントが連携していなければ、LinkSenseで確認メッセージを受け取り、それをボットに非公開で送信してください。 未登録または無効化されたアカウントはタスクを開始できません。 利用可能なモデルと十分なノルマを設定するか、必要に応じて管理者に連絡してください。

### リンク解除または切断 [#dingtalk-unlink-or-disconnect]

**アカウント連携を解除**このDingTalkのIDがLinkSenseを使うのを防ぎ、後で再度リンクできるようにします。 DingTalkを切断すると、接続、アイデンティティアソシエーション、キューに入ったチャネルメッセージが削除されます。 既存のLinkSenseタスクとDingTalkのボットは保持されます。

## 接続してMicrosoft Teamsを活用しましょう [#teams]

### 管理者設定 [#teams-administrator-setup]

1. Microsoft Entraでパブリッククラウドのシングルテナントアプリケーションを登録し、クライアントシークレットを作成します。 同じアプリケーションIDとテナントのAzure Botを作成し、Microsoft Teamsチャンネルを有効にしてください。
2. LinkSenseで**管理 → システム設定 → 組織のメッセージチャネル**を開き、**Connect Microsoft Teams**を選択します。 アプリケーションを入力してください。クライアントID、シークレット、テナントID。 メンバーがグループでボットについて言及できるかどうかを選び、セーブしてください。 会員IDは不要です。
3. 表示された**メッセージングエンドポイント**をAzure Botにコピーしてください。 アドレスはHTTPSを通じて公開可能でなければなりません。
4. 必要な個人、グループチャット、またはチームのスコープを備えたボットを含むTeamsアプリパッケージを作成します。 組織管理者に承認、インストール、またはメンバーへの配布を依頼してください。

管理者は接続を維持し、一時停止、有効化、切断が可能です。 メンバーはアカウントをリンクするのにアプリケーションの認証情報やディレクトリ読み取り権限を必要としません。 Teamsのサインイン設定とボットメッセージ設定は別々に管理されています。

### 会員アクセス [#teams-member-access]

1. ご自身の既存の有効なLinkSenseアカウントにサインインし、**設定 → メッセージチャネル**を開きます。
2. Microsoft Teamsカードの**自分のアカウントを連携**を選択すると、確認メッセージが表示されます。
3. 完全なメッセージをプライベートチャットでTeamsボットに送信してください。 有効期限は10分、使用は1回です。 他の誰にも転送しないでください。
4. ページが**アカウント連携済み**表示されたら、プライベートテキストを送るか、許可されたグループチャットやチャンネルでボットの名前を伝えてください。

タスクは送信者自身のLinkSense権限、リソース、ノルマを使用します。 未登録、無効、または連携解除されたアカウントはタスクを開始できません。 メンバーは同じグループ内で別々のタスクコンテキストを持ちます。チャンネル投稿も別々のスレッドを保持しています。 グループの返信はメンバーにも引き続き表示されます。

### 範囲とトラブルシューティング [#teams-scope-and-troubleshooting]

テキストもサポートしています。 画像、ファイル、音声、カードはまだサポートされていません。 localhostのみでアクセス可能なアドレスはTeamsのメッセージを受け取れません。

管理者は、メッセージが失敗した場合、アプリケーションID、テナント、シークレット、Teamsアプリのスコープ、組織承認、公開HTTPSエンドポイント、ネットワークを確認する必要があります。 メンバーは自分のアイデンティティをメッセージチャンネルから解除できます。

アプリケーションやシークレットを置き換えるために、管理者は切断して再度設定します。メンバーはその後、再びアカウントを連携します。 切断すると、既存のLinkSenseタスクは保持しつつ、関連付けとキューにされたチャネルメッセージが削除されます。
