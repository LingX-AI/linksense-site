---
title: "展開を選択する"
description: "知識要件と計画容量に基づいてCoreかFullを選択します。"
---

LinkSenseは自分のサーバーやプライベートクラウド上で動作可能です。 CoreとFullは同じ製品コードを使い、組み込みのナレッジサービスを展開するかどうかで異なります。

## CoreとFull [#core-and-full]

| 版            | 含まれる                                                                                           | 選ぶのはいつだ                                                                         |
| ------------------ | -------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| [Core](./core.mdx) | エージェントワークスペース、タスクアタッチメント、スキル、プラグイン、MCP、アプリケーション、組織管理 | 組織の知識には組み込みの解析、インデックス作成、検索機能は必要ありません。 |
| [Full](./full.mdx) | Core プラス Elasticsearch と Docling による組み込み知識                                  | 組織文書の処理、検索、引用が必要です。                      |

## 計画資源 [#plan-resources]

| 版 | 評価の出発点            | Dockerメモリプリフライト                                                 |
| ------- | ------------------------------------ | ----------------------------------------------------------------------- |
| Core    | 4 vCPUと60 GiBの空きSSD容量  | 8 GiB                                                                   |
| Full | 8 vCPUと120 GiBの空きSSD容量 | v0.3.13を新規インストールする場合は10 GiB。選択したリリースのマニフェストを確認してください |

Docker Desktopのメモリを割り当てる際にはVMのオーバーヘッドを考慮してください。 16 GiB Macなら、まずCoreから始めて、10–12 GBをDocker Desktopに割り当て、その後メモリのDocker Engineレポートを確認してください。

組織Full展開では、16 vCPU、32 GiBのメモリ、200 GiBの空きSSDスペースでキャパシティプランニングを開始します。 これらの推奨は外部モデルAPIを前提としています。 ローカル推論用の計算とGPUは別々に計画してください。 ピークの同時実行時に実際のワークロードをテストし、大きなドキュメントやOCRも含めてテストします。 プリフライト通過はピーク容量を確定しません。

## 設置方法を選びましょう [#choose-an-installation-method]

- Dockerの準備、ホストリソース、レジストリアクセス:[Dockerとネットワークの準備をする](./prepare.mdx)に従ってください。
- 公開されたDockerイメージをインストールする:[Core](./core.mdx)または[Full](./full.mdx)ガイドを開きます。 ソースチェックは不要です。
- コーディングエージェントを使いましょう。[リポジトリインストールガイド](https://raw.githubusercontent.com/LingX-AI/linksense/main/Install.md)とデプロイの目標を伝えましょう。
- コードを変更するかイメージを構築するか、[ソース開発](./development.mdx)をフォローしてください。
- 既存のインストールを管理する:まず[運用、修理、アップグレード](./operations.mdx)から始めましょう。
