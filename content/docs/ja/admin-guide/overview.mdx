このガイドは誰でも読めますが、LinkSenseの管理ページや運営にはアクティブな管理者アカウントが必要です。

<Callout type="info" title="管理者の運用">

管理は設定の**管理**グループの中に表示されます。 サーバーはすべてのリクエストに対して役割とステータスを検証します。隠しメニューはセキュリティの境界線ではありません。

</Callout>

## 管理区域 [#administration-areas]

| ページ | 責任 |
| --- | --- |
| ユーザーとグループ | アカウント作成、ユーザーのインポート、ステータス管理、フラットグループの管理 |
| 役割と権限 | 固定されたユーザーと管理者の境界を見直してください |
| プラグインセンター | リリースのレビューやリスクの高いリスティングの停止または回復 |
| ナレッジベース | メタデータ、状態、アクセス、所有権をガバナンス |
| 知識源 | SharePointなどの外部ソースを設定する |
| モデル設定 | チャット、検索、文字起こし、画像理解、画像生成モデルと価格の管理 |
| システム設定 | サポートする製品および認証設定の管理 |
| システムヘルス | 依存関係、実行時、コンテナリソース、失敗したクリーンアップを検査します |
| ユーザーフィードバック | ユーザーが投稿したテキストや問題のスクリーンショットを確認してください |
| 監査ログ | 永久イベント、タスク実行メタデータ、削除タスクアーティファクトの要約をクエリ |
| 使用例 | タスク、ターン、モデル、トークン、コストを分析します |
| システムアップデート | 公式バージョンを確認し、安全な展開アップグレードプロセスを守ってください |

## コンテンツ管理者は受け取りません [#content-administrators-do-not-receive]

この役割は、他のユーザーのタスク本体、添付ファイル、成果物、個人能力コンテンツ、知識ベースのドキュメント内容を自動的に付与するものではありません。 パスワード、トークン、APIキー、接続文字列、暗号化された秘密は一切明かしません。

## 初期セットアップ [#initial-setup]

初期化されていないデプロイメントでは、最初のローカル管理者を作成するワンタイムウィザードが表示されます。 このアカウントはスーパー管理者ではなく、後の管理者と同じ役割を持っています。

## 動作原理 [#operating-principles]

- モデルを無効化、削除、転送、切り替えする前にスコープを確認してください。
- 不可逆的な行動のためにビジネス承認の証拠を保管してください。
- 管理結果を監査記録で確認しましょう。
- 診断にはシステムヘルスを使用し、その後、展開認可オペレーターにインフラ構成の変更を任せます。
