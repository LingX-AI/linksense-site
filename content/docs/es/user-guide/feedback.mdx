## Envía tus comentarios [#submit-feedback]

1. Selecciona el botón **Comentarios y ayuda** signo de interrogación en la barra lateral de LinkSense.
2. Selecciona **Comentarios**.
3. Describe la página, los pasos, el resultado esperado y el resultado real.
4. Añade capturas de pantalla si es útil, o pega imágenes directamente en el campo de feedback.
5. Revisa el contenido y selecciona **Enviar**.

El texto de retroalimentación puede contener hasta 2.000 caracteres. La página muestra el número máximo de imágenes y el tamaño por imagen. Se soportan PNG, JPEG, WebP y GIF. No se envían imágenes que superen los límites de formato, tamaño o conteo.

## Qué incluir [#what-to-include]

Incluye el tiempo, los pasos reproducibles, el código de error visible y el impacto cuando sea posible. No envíes contraseñas, tokens, claves API, enlaces de un solo uso, códigos QR, conjuntos de datos completos de clientes ni capturas de pantalla sensibles no relacionadas.

## ¿Qué pasa después? [#what-happens-next]

Una presentación exitosa significa que el feedback se almacenó; No significa que el problema se haya solucionado automáticamente ni que la respuesta esté garantizada dentro de un plazo determinado. Los administradores activos pueden leer y responder a los comentarios y eliminarlos permanentemente junto con sus respuestas. Para soporte urgente, utiliza también el canal de soporte aprobado por tu organización.


## Consulta tus comentarios [#view-your-feedback]

Abre **Configuración → Mis comentarios**, justo debajo de **Tareas archivadas**, para ver tus propias publicaciones, las más recientes primero. Cada fila muestra su estado de respuesta:

- **Pendiente de respuesta**: Ningún administrador ha respondido todavía.
- **Respondido**: Un administrador ha enviado al menos una respuesta.

Selecciona **Ver** para leer los comentarios originales, las imágenes y las respuestas cronológicas. Selecciona una imagen para ampliarla. **Respondido** no significa que el problema esté resuelto ni indica si has leído la respuesta. Selecciona **Actualizar** para cargar las últimas actualizaciones.
