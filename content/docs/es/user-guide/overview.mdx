---
title: "Resumen de la guía de usuario"
description: "Aprende los puntos principales de entrada de LinkSense y un flujo de trabajo recomendado."
---


LinkSense está organizado en torno a las tareas. Una tarea mantiene conjuntas tus conversaciones, archivos y entregables, permitiéndote seleccionar plugins, habilidades y bases de conocimiento.

## Principales zonas [#main-areas]

| Área | Propósito |
| --- | --- |
| Nueva tarea | Envía una solicitud y elige un modelo, modo Plan u Objetivo, y capacidades |
| Automatizaciones | Repite el trabajo cada hora, diario, semana o mes en una sola tarea fija |
| Centro de Plugins | Descubrir, instalar, actualizar y gestionar plugins, Skills, MCP y aplicaciones |
| Biblioteca de recursos | Gestionar bases de conocimiento, explorar artefactos de tareas y publicar o mantener sitios públicos |
| Escenarios | Gestiona el idioma, el perfil, la personalización, los canales de mensaje, la seguridad, las credenciales y el MCP |
| Comentarios y ayuda | Envía comentarios y ayuda abierta para la página actual |

La **Biblioteca de recursos** entrada utiliza un icono que muestra varios libros verticales. **Bases de conocimiento** gestiona documentos buscables y el intercambio, **Resultados de tareas** reúne archivos generados por tus tareas y **Mis sitios** gestiona páginas públicas publicadas a partir de entregables HTML.

## Primeros pasos recomendados [#recommended-first-steps]

1. Inicia sesión y confirma el idioma de la interfaz.
2. Crea una primera tarea y revisa su estado de ejecución y resultado.
3. Añade archivos, plugins, habilidades o bases de conocimiento según sea necesario, o pide a LinkSense que genere una imagen.
4. Utiliza la actividad y la visión general de tareas para revisar el progreso, los artefactos y las fuentes externas.
5. Sigue refinando el resultado. Para historias largas, revisa el uso de la ventana de contexto y el contexto compacto cuando sea necesario.
6. Utiliza el modo Plan para trabajos complejos, o ramifica desde una respuesta histórica para probar una dirección diferente.
7. Crea una automatización para el trabajo repetitivo, o convierte un flujo de trabajo estable en una aplicación compartida.

## Tu límite de datos [#your-data-boundary]

- Solo puedes leer tus propias tareas, mensajes, archivos adjuntos y entregables.
- Se puede leer y buscar una base de conocimiento compartida, pero solo su propietario gestiona los documentos y el intercambio.
- Los plugins personales, skills, credenciales y servidores MCP solo se usan para tus tareas.
- Los administradores gobiernan las cuentas y las capacidades de la plataforma, pero la interfaz de auditoría no expone el cuerpo de tareas ni el contenido de los archivos de otro usuario.
