Qualquer pessoa pode ler este guia, enquanto as páginas administrativas e operações do LinkSense exigem uma conta de administrador ativa.

<Callout type="info" title="Operação administrativa">

Administração aparece no grupo **Gerenciamento** em Configurações. O servidor valida o papel e o status em cada solicitação; Um menu oculto não é o limite de segurança.

</Callout>

## Áreas administrativas [#administration-areas]

| Page | Responsabilidade |
| --- | --- |
| Usuários & grupos | Crie contas, importe usuários, controle status e mantenha grupos planos |
| Funções e permissões | Revise os limites fixos de usuários e administradores |
| Centro de Plugins | Revise os lançamentos e suspenda ou restaure os anúncios de risco |
| Bases de conhecimento | Governar metadados, estado, acesso e propriedade |
| Fontes de conhecimento | Configure fontes externas, como SharePoint |
| Configurações do modelo | Gerencie modelos e preços de chat, recuperação, transcrição, compreensão de imagens e geração de imagens |
| Configurações do sistema | Gerencie as configurações de produto e autenticação suportadas |
| Saúde do sistema | Inspecionar dependências, runtime de execução, recursos de contêiner e falhas na limpeza |
| Feedback dos usuários | Revise o texto e as capturas de tela dos problemas enviadas pelos usuários |
| Registros de auditoria | Consultar eventos permanentes, metadados de execução de tarefas e resumos de artefatos de tarefas excluídas |
| Uso | Analise tarefas, turnos, modelos, tokens e custos |
| Atualização do sistema | Verifique as versões oficiais e siga o processo de atualização de implantação segura |

## Administradores de conteúdo não recebem [#content-administrators-do-not-receive]

O papel não concede automaticamente o corpo da tarefa de outro usuário, anexos, entregáveis, conteúdo de capacidade pessoal ou conteúdo de documentos de base de conhecimento. Ele nunca revela senhas, tokens, chaves API, strings de conexão ou segredos criptografados.

## Configuração inicial [#initial-setup]

Uma implantação não inicializada mostra um assistente de uso único que cria o primeiro administrador local. Esta conta não é um super administrador e tem o mesmo papel que administradores posteriores.

## Princípios de funcionamento [#operating-principles]

- Confirme o escopo antes de desativar, excluir, transferir ou trocar de modelo.
- Mantenha evidências de aprovação empresarial para ações irreversíveis.
- Verifique os resultados da gestão com registros de auditoria.
- Use a Saúde do Sistema para diagnóstico e depois deixe operadores autorizados para implantação alterarem a configuração da infraestrutura.
